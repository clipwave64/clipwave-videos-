# ClipWave videos

The automatic video machine for **@clip.wave64** (TikTok, Instagram Reels, YouTube Shorts).

Every morning Claude researches trending topics, makes 3 short fact videos, uploads them to `videos/`, and schedules them in Metricool for the next day.

- `engine/`: the video generator
- `scripts/`: the script for every video
- `videos/`: finished videos, by posting date (deleted after 7 days)
- `DAILY.md`: the step-by-step instructions the daily run follows
